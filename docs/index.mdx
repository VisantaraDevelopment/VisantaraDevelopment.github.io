# 📖 Nature Series Documentation

Selamat datang di pusat panduan item kustom. Gunakan menu di samping untuk melihat detail kemampuan dan resep crafting.

### ⚡ Fitur Utama
* **Forging System**: Semua item memerlukan waktu tempa selama 1 jam.
* **Unique Materials**: Kumpulkan material langka dengan drop rate khusus dari alam.
* **Elemental Powers**: Kekuatan Nature yang mencakup efek Poison, Fire, Lightning, Ice, dan Earth.

---

:::tip[Cara Memulai]

Klik **Nature Series Introduction** di sidebar untuk memahami klasifikasi elemen atau langsung pilih item spesifik di kategori **Custom Items**.

:::
